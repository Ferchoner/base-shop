# TEAM GUIDE

## Principios

- La documentación es parte del producto.
- Las decisiones importantes se registran.
- Los cambios deben ser pequeños y revisables.
- Ningún miembro depende exclusivamente de una conversación con una IA.
- Git es obligatorio como mecanismo de historial y recuperación.

## Trabajo con IA

La IA puede:

- analizar;
- proponer;
- implementar;
- probar;
- documentar;
- revisar.

La IA no sustituye la aprobación humana de decisiones de arquitectura, negocio, seguridad o despliegue.

## Revisión humana

Requiere revisión humana cualquier cambio que afecte:

- seguridad;
- pagos;
- datos personales;
- arquitectura;
- migraciones destructivas;
- permisos;
- infraestructura;
- costos significativos.

## Comunicación

Cada tarea debe dejar un registro claro de:

- qué se hizo;
- por qué;
- cómo se verificó;
- qué queda pendiente.
